## 🎯 项目概述

**CosmicChart** 致力于将中国传统命理学术数字化、系统化、引擎化。区别于传统纯前端排盘工具，本项目采用 **前后端分离架构**，所有核心排盘算法均在服务端完成，确保：

- **计算精度**：复杂天文历法、真太阳时、节气交接时刻由 Java 后端精确运算
- **数据资产**：用户命盘、排盘历史、运势记录持久化存储于 MySQL
- **多端适配**：Web 端、移动端浏览器均可访问，未来可扩展小程序与 App

## 🚀 快速开始

### 环境要求

- **JDK 17+**
- **Node.js 18+**
- **MySQL 8.0+**
- **Redis 7.0+**（可选，用于缓存）

### 1. 克隆仓库

```bash
git clone https://github.com/YOUR_USERNAME/CosmicChart-Metaphysics-Engine.git
cd CosmicChart-Metaphysics-Engine
```

### 2. 初始化数据库

```bash
mysql -u root -p < sql/init_schema.sql
mysql -u root -p < sql/init_data.sql
```

### 3. 启动后端服务

```bash
cd backend
mvn clean install
java -jar target/cosmicchart-backend-1.0.0.jar
```

后端默认运行在 `http://localhost:8080`

### 4. 启动前端开发服务器

```bash
cd frontend
npm install
npm run dev
```

前端默认运行在 `http://localhost:5173`

### 5. 访问系统

浏览器打开 `http://localhost:5173`，注册账号后即可开始排盘。

## 🧮 算法说明

本项目所有术数算法均基于经典古籍与现代天文历法实现：

- **紫微斗数**：参考《紫微斗数全书》《紫微斗数全集》，采用中州派与三合派双算法
- **四柱八字**：基于《渊海子平》《三命通会》，节气划分采用紫金山天文台数据
- **奇门遁甲**：依据《奇门遁甲统宗》《神奇之门》，支持转盘与飞盘双法
- **大六壬**：参考《六壬大全》《六壬指南》，四课三传严格按古法推演
- **七政四余**：基于《果老星宗》《七政四余推步》，星体位置采用现代天文算法校正
- **神煞**：综合《协纪辨方书》《神峰通考》等典籍
