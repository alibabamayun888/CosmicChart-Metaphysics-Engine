# CosmicChart 天元命盤｜中國傳統術數排盤引擎

[简体中文](README.md) | [繁體中文](README.zh-TW.md) | [English](README.en.md) | [專案首頁](https://alibabamayun888.github.io/CosmicChart-Metaphysics-Engine/zh-TW/)

**CosmicChart Metaphysics Engine（天元命盤引擎）**是一個面向中國傳統術數數位化研究的 Web 排盤專案。線上儲存庫目前包含 HTML、JavaScript、Layui 資源及命理排盤頁面，展示手動排盤、八字刑沖關係、七政四餘參數設定、五行運勢曲線與排盤歷史等功能介面。

專案圍繞四柱八字、奇門遁甲、七政四餘、紫微斗數、大六壬和神煞等術數主題組織文件。README 只陳述目前儲存庫或產品截圖能夠確認的內容；若後續發布 Java/Spring Boot、Vue、MySQL 或 API 服務，應同步提交對應原始碼和可執行文件。

## 專案概述

CosmicChart 將傳統命理排盤的輸入、計算結果和視覺化介面轉化為便於研究與擴充的 Web 工程。目前截圖展示出生時間、流年時間、時區、經緯度、農曆設定、星曜選擇、刑沖關係和五行趨勢等互動。

| 能力 | 目前可見內容 |
| --- | --- |
| 排盤參數 | 姓名、性別、出生時間、流年時間、曆法、時區、經緯度 |
| 八字關係 | 年柱、月柱、日柱、時柱、大運和流年等柱位關係 |
| 刑沖分析 | 刑、沖、合、害等關係的圖形化顯示 |
| 七政四餘 | 七政及四餘星曜選擇、地區與時間參數設定 |
| 五行運勢 | 指定時間範圍的趨勢曲線 |
| 歷史記錄 | 儲存、載入和管理排盤記錄的介面 |

## 術數模組

### 四柱八字

圍繞年柱、月柱、日柱、時柱、十神、藏干、大運、流年及刑沖合害關係組織排盤和分析介面。

### 奇門遁甲

儲存庫根目錄包含 [`qimen.html`](qimen.html)。實際排局方法和演算法範圍應以該頁面及其引用程式碼為準。

### 七政四餘

產品截圖展示七政四餘參數頁，可選擇七政、四餘及其他星曜，並設定時間、時區和經緯度。

### 紫微斗數、大六壬與神煞

這些模組出現在現有專案定位與頁面導覽中。若要聲明完整演算法能力，建議補充原始碼入口、範例輸入輸出、測試案例和參考文獻。

### 數位資產週期研究

線上 README 提到以傳統星曆方法觀察數位資產週期。此類內容僅適合文化或學術研究，不能用於承諾價格、收益或交易時點。

## 核心介面

- **手動排盤**：輸入人物、時間、曆法、時區和經緯度資料。
- **刑沖關係圖**：顯示不同柱位間的刑、沖、合、害關係。
- **七政四餘參數**：設定星曜、時間、流年、時區和地理座標。
- **五行運勢與歷史**：顯示趨勢曲線並儲存或載入排盤記錄。

## 常見問題

### CosmicChart 是什麼？

它是中國傳統術數 Web 排盤與視覺化專案，目前可見 HTML、JavaScript、Layui 資源，以及八字、七政四餘和趨勢分析畫面。

### 是否包含完整 Java 後端與 Vue 前端？

目前線上根目錄沒有顯示 `backend/` 或 `frontend/`，因此不能據此宣稱已提供完整服務端。

### 排盤結果可否作為專業決定依據？

不可。術數結果屬傳統文化與娛樂研究，不應替代醫療、法律、財務、投資或心理專業意見。
